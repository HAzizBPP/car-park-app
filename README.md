# Enterprise Car Park Booking System

A web-based Single Page Application (SPA) designed to solve office parking allocation, waitlist management, and real-time bay availability.

## Technical Stack & Architecture
- **Frontend:** React, Vite, CSS
- **Backend:** Node.js, Express
- **Persistence:** Structured JSON file storage (`employees.json`, `ledger.json`)
- **Deployment Target:** AWS Amplify

## Advanced Programming Concepts Implemented
- **Data Structures:** JavaScript `Map` (employee lookup), `Set` (duplicate validation), 2D Array (parking grid), Queue (FIFO waitlist)
- **Input Validation & Safety:** Strict validation on date selection and user authorization
- **Error Handling:** Comprehensive HTTP status error responses and boundary validations
